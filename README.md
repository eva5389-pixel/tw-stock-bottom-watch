# 台股止跌觀察 Taiwan Bottom Watch

貼近盤後研究流程的繁體中文 Streamlit 網頁工具。從證交所取得公開資料，列出價格、成交金額、市場廣度、融資及外資現貨的觀察依據，區分「仍創新低」「反彈／築底觀察」與「止跌訊號增加」。

**不是預測模型、勝率、底部保證或自動交易工具。人工規則尚未做績效回測。**

## 使用

需要 Python 3.11 以上。第一次載入需連線至證交所；沒有 API 金鑰或付費資料依賴。

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Windows 啟用環境請改用 `.venv\Scripts\activate`。瀏覽器開啟終端機顯示的本機網址。

1. 選擇觀察截止日期（預設台北時間昨天）。
2. 按「更新止跌觀察」，首次約30–90秒，遇來源逾時可能更久。
3. 先看結論與資料日期，再看各項支持／未支持／資料不足的原因。
4. 可下載 Markdown 觀察報告、UTF-8 CSV 行情與籌碼。

查詢結果快取一小時；勾選重新取得資料可清除快取。切換日期後需按更新才套用，頁面會提醒舊結果。來源不可用時明確報錯，不使用模擬資料。

## 部署為網頁

在 [Streamlit Community Cloud](https://share.streamlit.io/) 建立 app，選擇此 repository、`main` 分支、`streamlit_app.py`，Python 建議 3.11 或 3.12。GitHub 存放程式本身不會自動產生可用網站；GitHub Pages 無法直接執行本 Python 後端。

此專案不含憑證，不要上傳 `.env` 或 `.streamlit/secrets.toml`。雲端 IP 可能被資料來源限流；若無法取得資料，應重試或在本機執行，不會繞過來源存取限制。

## 六項觀察條件

| 項目 | 支持條件 |
|---|---|
| 近三日守前低 | 最近三日低點均不低於此前20日最低價；且今日未破此前20日低點 |
| 均線修復 | 收盤在5日與20日均線上，5日均線上彎 |
| 上漲有成交金額配合 | 收盤上漲，成交金額至少為此前20日平均的1.10倍 |
| 多數股票參與 | 最近3日至少2日的上漲家數占上漲＋下跌＋持平家數超過50% |
| 融資減少且價格守穩 | 近5交易日融資淨變動為負，且近三日守前低 |
| 外資現貨賣壓改善 | 近3日合計買超或持平，或相較前3日賣超金額縮小 |

這些門檻是觀察規則，未經統計驗證。支持項目數不是勝率，不表示各項獨立，也不能加總為報酬預測。

### 結論優先順序

1. 指數月份擷取缺漏，或最新資料落後截止日超過7個日曆日：資料不足、暫不判斷。7日僅為資料警示，長假也可能觸發。
2. 當日最低價跌破此前20交易日低點：仍創新低，止跌未確認，優先於任何支持項目。
3. 較高低點後突破成立、六項資料齊全且至少四項支持：止跌訊號增加，仍需持續確認。
4. 近三日守前低且收盤高於5日線：反彈／築底觀察，尚未確認。
5. 其餘：止跌未確認。

### 「較高低點後突破」的明確定義

在最近40交易日尋找已確認波段低點：當日最低價低於左側2日低點，且不高於右側2日低點。只有兩根右側日K已出現才確認，沒有利用截止日之後資料。

取最近兩個低點，至少間隔3個交易日。第一低點須距此前最多20日最高價下跌至少3%；第二低點高於第一個，之後沒有跌破第二低點，最新收盤突破兩個低點中間的最高價，才成立。

這是保守的固定型態規則，可能漏掉V型反轉或較長期底部；站上均線也可能是假突破。圖中前20日低點不是固定停損指令或保證支撐。

## 官方資料來源與範圍

| 資料 | 證交所報表 | 單位／範圍 |
|---|---|---|
| 加權指數日OHLC | [MI_5MINS_HIST](https://www.twse.com.tw/indicesReport/MI_5MINS_HIST?response=json) | 指數點數，四個日曆月 |
| 成交金額 | [FMTQIK](https://www.twse.com.tw/exchangeReport/FMTQIK?response=json) | 原始元；畫面換成億元；含市場其他證券 |
| 股票漲跌家數 | [MI_INDEX](https://www.twse.com.tw/exchangeReport/MI_INDEX?response=json&type=MS) | 僅「股票」欄，排除整體市場權證干擾 |
| 融資餘額與償還 | [MI_MARGN](https://www.twse.com.tw/exchangeReport/MI_MARGN?response=json&selectType=MS) | 原始仟元÷100,000＝億元 |
| 外資現貨買賣超 | [BFI82U](https://www.twse.com.tw/rwd/zh/fund/BFI82U?response=json) | 外資及陸資、不含外資自營商；元÷100,000,000＝億元 |

價格抓四個月；籌碼抓最近六個已知指數交易日。各來源日期必須符合查詢日期，缺值不填零、不拿前一天頂替。月資料只採截止日及以前的列。

融資「前日餘額」可能經證交所更正。本程式每日變動採同份日報的今日餘額減前日餘額，再加總五日；不強制把跨報表餘額接成完全一致。依據來源欄位核對買入－賣出－現金償還＝餘額變動。餘額減少不等於斷頭。

外資買賣超不等於跨境資金匯出入。沒有取得實際融資戶成本與整戶維持率，因此不計算全市場斷頭價。

**本版只有上市市場，不含櫃買、個股創新低家數、期貨法人部位或盤中即時報價。** 不應據此代表全部台股與所有個股。官方歷史數據可能更正，歷史日期重跑也不等於當時可見資訊的完整回測。

```bash
python -m unittest discover -s tests -v
```

測試涵蓋新低優先、缺資料不當作零、較高低點突破與失效、截止資料限制、陳舊資料、單位、股票／權證欄位、日期核對及 Streamlit 畫面。測試中的合成行情只存在於測試，正式程式不提供假行情。

GitHub Actions 每次 push / pull request 執行離線測試。真實來源需要另外驗證，離線測試不代表外部服務隨時可用。

## 當日資料與大台多單壓力試算
日期預設今天，可查當日已公布盤後資料；快取5分鐘，可手動強制更新。若今天尚無指數資料，顯示最新實際交易日期，不能視為當日結論。各日籌碼缺值不補零、不沿用前日。

大台試算獨立使用：先載入期交所目前原始／維持保證金及最近近月一般時段收盤快照，或手動輸入期貨商要求。輸入目前帳戶權益（含浮動損益）與口數，計算維持保證金追繳及可調整風險比率門檻。預設假設權益剛好等於原始保證金，並非使用者真實帳戶。

每口每點200元，僅適用單一大台多單、現金權益、無其他商品或加收。追繳未依期限補足亦可能先被強平；25%僅為示例，依期貨商契約。門檻是期貨點數，不是加權指數或全市場斷頭預測。跳空及滑價影響實際成交。
